# Doris SQLTools Lite 使用

按 0.9.1 能力核对（2026-10-27）。负责工具使用与 SQL 交付格式；业务口径、表结构、方言、文件归属和执行权限沿用当前任务及项目规则。版本行为不符时再核对目标版本说明，不默认改设置、安装扩展或连接数据库。

## 编写 SQL 文件

从现有上下文确认目标引擎、已保存连接的真实名称或 ID、参数取值和语句用途。连接名称精确匹配，重名时使用 ID；查不到时只澄清缺失项，或明确标为待填草案，不编造可用连接。SQL 注释只引用连接名称或 ID，不写账号密码、主机或连接串。

| 注释 | 作用与位置 |
| --- | --- |
| `-- @default-connection: 连接名称或ID` | 文件默认连接，只能写在第一条 SQL 之前 |
| `-- @default-param: 参数名 = 值` | 文件默认参数，每个参数一行，只能写在第一条 SQL 之前 |
| `-- @name: 语句用途` | 紧接该条 SQL 前，显示在进度、结果页和计划材料中 |
| `-- @connection: 连接名称或ID` | 覆盖当前语句的连接，不延续到下一条 |
| `-- @param: 参数名 = 值` | 覆盖当前语句的参数，不延续到下一条 |

为独立语句写有业务含义的 `@name`。注释字段使用上述英文小写与半角冒号；同一范围内不重复声明同一设置或参数。只有 SQL 前的 `--` 注释有效，块注释和 SQL 正文中的同名文字不作为配置。

示例中的连接名、日期和表名需要替换为当前任务已确认的值：

```sql
-- @default-connection: Spark数仓
-- @default-param: c_date = 2026-10-26

-- @name: 订单日汇总
SELECT dt, COUNT(*) AS order_count
FROM orders
WHERE dt = '${c_date}'
GROUP BY dt;

-- @name: Doris 对照核查
-- @connection: Doris数仓
-- @param: c_date = 2026-10-25
SELECT COUNT(*) AS order_count
FROM order_summary
WHERE dt = '${c_date}';
```

参数优先级：当前语句注释 > 文件默认注释 > `${name=default}` 行内默认值。值按原文替换，不自动加引号或转义；日期和文本通常写在 SQL 的 `'${c_date}'` 中，数值按目标类型使用。注释值不能为空，逗号、等号和分号仍属于值，不表示候选列表。`$${name}` 表示把 `${name}` 原样交给服务端。

参数齐全直接执行，缺值才打开参数页；注释值在参数页只读，应回编辑器修改。不要让历史记忆值替代已确认的注释值，不跨文件共享参数。正式调度 SQL 继续使用其原有传参，不为手工工具硬编码业务日期或插入参数赋值。

## 查看计划、审核与执行

复杂或大结果查询按任务需要先看计划，再审核、执行和导出；普通小查询不因此增加审批步骤。

- `Ctrl+Alt+Enter` 或 `Doris SQL Lite: Explain Query at Cursor`：对光标所在或选中的单条 SQL 取计划，复用该语句的连接、参数和会话，不修改原 SQL。Spark 使用 `EXPLAIN FORMATTED`，Doris 使用 `EXPLAIN VERBOSE`，MySQL 使用普通 `EXPLAIN`。此入口不自动使用 `EXPLAIN ANALYZE`，不要为取计划重复维护两份 SQL。
- 计划页可复制或保存 AI 审核材料，包含 SQL 名称、来源、连接名称/类型、实际参数、解析后的 SQL、完整计划和审核要求。材料保存位置与业务信息管理遵循当前项目约定。
- 收到计划后，结合 SQL 和参数检查分区裁剪、扫描范围、过滤、Join、Shuffle/Exchange、排序与聚合。区分计划证据、估算和实际运行结果；SQL、参数、连接或会话配置改变后，原计划不能作为新版本已审核的证据。
- `Ctrl+Enter` 或 `Doris SQL Lite: Run Query at Cursor`：一次执行一条 SQL。有选区取选中语句，否则取光标所在或最近一条；只选正文仍继承前面的注释，跨多条的选区会被拒绝。

生成 SQL、取到计划或通过审核，不等于已经执行成功。执行由当前任务授权决定；本 skill 本身不增加生产访问权限，也不自动将材料发给 AI。

## 结果导出与会话

- 预览默认最多保留 1000 行，并可能追加 `LIMIT` 或提前停止读取；截断或提前停止时不能据显示行数推断总数。计划按原 SQL 完整获取，不追加预览 `LIMIT`。
- 复制 TSV 只取面板保留的行。排序与筛选只作用于已加载行，不改变复制和导出的内容或顺序。全量数据使用现有“导出 TSV”，UTF-8、无 BOM；默认启用表格公式转义，需原值时按下游要求处理该设置。
- 完整保留的结果直接导出。截断结果会在原会话重跑原查询，数据以重跑时为准；同一会话执行过其他语句（包括查看计划和失败的语句）、关闭、断线或重置后，旧结果不能重跑导出，需要重新查询。因此需要全量结果时，在本次查询后及时导出，不在中间插入其他语句。
- 每个文件按连接 ID 保留独立会话，切换数据源再回来保留原 `USE`、`SET` 等状态；不同文件互相隔离。同一文件的查询、计划、参数选择和导出互斥，其他文件可独立执行。
- 取消可用进度通知、状态栏或 `Doris SQL Lite: Cancel Query`。取消后会话仍健康则保留；已断开时重新执行必要初始化，不自动重放或重试失败语句。
- 关闭文件、重置会话、修改连接目标/认证信息等会释放相应会话。`Doris SQL Lite: Reset This File's Sessions` 取消当前操作并重置该文件全部会话；之后重新执行初始化。连接按实际使用懒建立，不自动回收空闲会话，多文件、多数据源会增加保留的连接数。

当前未支持整文件批量执行、`@output`、一键执行并落盘及自动 AI 审核；交付时不要使用这些规划中的能力或发明其他指令。
