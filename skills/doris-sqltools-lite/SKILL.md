# Doris SQLTools Lite 使用

按 0.9.8 能力核对（2026-10-30）。负责工具使用与 SQL 交付格式；业务口径、表结构、方言、文件归属和执行权限沿用当前任务及项目规则。版本行为不符时再核对目标版本说明，默认沿用现有设置、安装状态和连接配置。

## 连接与传输

MySQL / Doris 使用 `ssl=true` 启用 TLS；`sslVerify` 默认开启，负责校验证书链，并在主机为 DNS 名称时校验主机名。私有 CA 通过 `sslCaFile` 指向本地 PEM 文件；`sslVerify=false` 对应接受服务器证书的显式兼容模式，使用前确认目标主机可信。Spark Thrift 使用所选 SASL/PLAIN 或 NOSASL 传输，连接表单中的 TLS 选项仅属于 MySQL / Doris。

## 编写 SQL 文件

从现有上下文确认目标引擎、已保存连接的真实名称或 ID、参数取值和语句用途。连接名称精确匹配，重名时使用 ID；查不到时只澄清缺失项，或明确标为待填草案，不编造可用连接。SQL 注释只引用连接名称或 ID，不写账号密码、主机或连接串。

| 注释 | 作用与位置 |
| --- | --- |
| `-- @default-connection: 连接名称或ID` | 文件默认连接，只能写在第一条 SQL 之前 |
| `-- @default-param: 参数名 = 值` | 文件默认参数，每个参数一行，只能写在第一条 SQL 之前 |
| `-- @default-encrypt: {"user_id":"user"}` | 文件默认保护字段及逻辑域，只能写在第一条 SQL 之前 |
| `-- @name: 语句用途` | 紧接该条 SQL 前，显示在进度、结果页和计划材料中 |
| `-- @connection: 连接名称或ID` | 覆盖当前语句的连接，不延续到下一条 |
| `-- @param: 参数名 = 值` | 覆盖当前语句的参数，不延续到下一条 |
| `-- @encrypt: {"space_id":"space"}` | 当前语句的保护字段及逻辑域，与默认合并，同名覆盖 |
| `-- @output: 路径.tsv` | 只为当前语句指定完整结果文件，`Ctrl+Enter` 执行一次并导出，取计划时忽略 |
| `-- @batch-script: ./backfill-params.ps1` | 文件头指定生成批次参数的 PowerShell 脚本，普通执行和计划不运行它 |
| `-- @batch-steps: ["清理当天", "回填当天"]` | 文件头指定每批执行的 `@name` 及顺序 |
| `-- @batch-init: ["会话设置"]` | 文件头指定任务开始时只执行一次的初始化步骤，可省略 |

为独立语句写有业务含义的 `@name`。注释字段使用上述英文小写与半角冒号；同一范围内不重复声明同一设置或参数。只有 SQL 前的 `--` 注释有效，块注释和 SQL 正文中的同名文字不作为配置。

示例中的连接名、日期和表名需要替换为当前任务已确认的值：

```sql
-- @default-connection: Spark数仓
-- @default-param: c_date = 2026-10-26

-- @name: 订单日汇总
-- @output: results/orders_2026-10-26.tsv
SELECT dt, COUNT(*) AS order_count
FROM orders
WHERE dt = '${c_date}'
GROUP BY dt;

-- @name: Doris 对照核查
-- @connection: Doris数仓
-- @param: c_date = 2026-10-25
SELECT COUNT(*) AS order_count
FROM order_summary
WHERE dt = '${c_date}';
```

参数优先级：当前语句注释 > 文件默认注释 > `${name=default}` 行内默认值。值按原文替换，不自动加引号或转义；日期和文本通常写在 SQL 的 `'${c_date}'` 中，数值按目标类型使用。注释值不能为空，逗号、等号和分号仍属于值，不表示候选列表。`$${name}` 表示把 `${name}` 原样交给服务端。

参数齐全直接执行，缺值才打开参数页；注释值在参数页只读，应回编辑器修改。不要让历史记忆值替代已确认的注释值，不跨文件共享参数。正式调度 SQL 继续使用其原有传参，不为手工工具硬编码业务日期或插入参数赋值。

## 字段密文与字段原文

需要保护字段时，按任务已确认的敏感范围声明结果列/AS 别名或 SQL 参数名，JSON 值为逻辑域。例如 `-- @default-encrypt: {"user_id":"user","owner_id":"user"}` 让同类标识可跨查询对照。相同密钥、域、类型和值对应相同完整 `enc:v1:…` 密文，保留相等关系；密文不是数字，不可截断或当作计数计算。跨源 ID 类型不同时按任务需要在 SQL 中统一类型，不能恢复驱动此前丢失的精度。

- 默认规则可在聚合结果中缺失；局部显式字段若不匹配结果列或实际参数，工具会停止展示/导出，先核对别名和拼写。受保护列名重复时使用唯一 `AS`；无结果集写入不因没有输出列报错。未声明字段继续原值输出，不声称全部数据都已保护。
- 窗口初始为字段密文模式；状态栏、结果/计划按钮或 `Doris SQL Lite: 切换字段密文 / 字段原文` 统一切换。预览切换不重跑 SQL；复制、导出、报告保存固定开始时的模式/规则/密钥，已有文件和剪贴板历史不会自动改写。参数表单固定打开时的模式，切换后重新打开。
- 已声明的 SQL 参数可直接填写完整密文，扩展在本机解密后按原引号/替换规则提交；不把密文写成数据库实际存储值，不在 SQL 正文中批量替换。密钥缺失、域不符、篡改会在提交前失败，批次也先校验所有参数。不用哈希或自建代号表替代可逆密文。
- 先看反馈 `dataMode`，以及 `protection.mode`、`keyId`、`fields`；批次步骤可能使用不同字段域。字段密文模式的结果、参数、进度和报告为已声明值的密文；字段原文与字段密文报告路径分别复用，跨模式既有 TSV 不当作当前模式的 `resultFile`。
- 有保护字段时，字段密文模式不展示/复制/保存 SQL、计划和自由错误原文，也不生成字段原文计划附件。需要计划审核或原文排错时，按当前任务允许的数据范围明确使用字段原文模式；不得绕过模式限制，把原 SQL 或明文附件拼入“字段密文材料”。取到加密摘要不等于已审核完整计划。
- 数据密钥独立保存在 SecretStorage。使用扩展的 `Doris SQL Lite: 导出字段加密密钥` / `导入字段加密密钥` 管理迁移；导出文件含敏感密钥，不能加入 SQL、反馈、日志或普通结果，不能代替查询结果给 AI。丢失密钥无法还原，导入保留旧密钥。
- 单个值用 `Doris SQL Lite: 解密选中字段值`，选完整密文或在命令中输入，再选择本机查看/复制明文；不依赖查询仍在内存。不擅自将其解释为整份历史 TSV 解密入口。

## 查看计划、审核与执行

复杂或大结果查询按任务需要先看计划，再审核、执行和导出；普通小查询不因此增加审批步骤。

- `Ctrl+Alt+Enter` 或 `Doris SQL Lite: 查看光标处执行计划`：对光标所在或选中的单条 SQL 取计划，复用该语句的连接、参数和会话，不修改原 SQL。Spark 使用 `EXPLAIN FORMATTED`，Doris 使用 `EXPLAIN VERBOSE`，MySQL 使用普通 `EXPLAIN`。此入口不自动使用 `EXPLAIN ANALYZE`，不要为取计划重复维护两份 SQL。
- 无保护字段或处于字段原文模式时，计划页“复制 AI 反馈 / 保存 AI 反馈…”提供简短信息，包含 SQL 名称、连接名称/类型、实际参数、原 SQL 路径和行号范围，以及完整计划的 `planFile` 路径，不重复 SQL 与计划正文。首次复制先选择 `.txt` 保存完整计划，取消则不复制；保存 `.md` 反馈时会同时生成相邻 `.plan.txt`。已保存计划后复用路径，需要全文快照才显式使用“复制完整材料”。材料保存位置与业务信息管理遵循当前项目约定。
- 收到反馈后，按路径读取来源 SQL 和完整计划，结合实际参数检查分区裁剪、扫描范围、过滤、Join、Shuffle/Exchange、排序与聚合。区分计划证据、估算和实际运行结果；SQL、参数、连接或会话配置改变后，原计划不能作为新版本已审核的证据。
- `Ctrl+Enter` 或 `Doris SQL Lite: 执行光标处 SQL`：一次执行一条 SQL。有选区取选中语句，否则取光标所在或最近一条；只选正文仍继承前面的注释，跨多条的选区会被拒绝。有 `@output` 时直接导出完整结果，无此注释时有结果集则显示预览，实际无结果集则只通知，零行 SELECT 仍显示空结果页；`Ctrl+Alt+Enter` 忽略输出注释，只取计划。

生成 SQL、取到计划或通过审核，不等于已经执行成功。执行由当前任务授权决定；本 skill 本身不增加生产访问权限，也不自动将材料发给 AI。

## 顺序分批补数

用于当前电脑、VS Code 保持打开的补数写入与初始化。每条 SQL 仍放在同一源文件，`.ps1` 只生成参数；连接和密码由扩展使用，不向脚本传递数据库密码。按当前任务确认每批过滤范围和步骤，工具不会把长时间区间自动改写为日/小时。

```sql
-- @default-connection: Doris数仓
-- @batch-script: ./backfill-params.ps1
-- @batch-steps: ["清理当天", "回填当天"]
-- @batch-init: ["会话设置"]

-- @name: 会话设置
SET time_zone = '+08:00';

-- @name: 清理当天
DELETE FROM order_summary WHERE dt = '${biz_date}';

-- @name: 回填当天
INSERT INTO order_summary
SELECT * FROM order_source WHERE dt = '${biz_date}';
```

连接和表名按任务实际替换；每步仍可单独声明 `@connection`、`@param`。名称精确匹配、全文件唯一；初始化与每批步骤不能重叠，不执行未列出的其他 SQL。初始化只用自身注释和行内默认值。每批参数优先级为：脚本当前批参数 > 语句 `@param` > 文件 `@default-param` > 行内默认值；不写回文件或参数记忆。

- SQL 先保存为本地文件；`.ps1` 路径不加外围引号，相对 SQL 文件解析，工作目录也是该文件目录。需受信任工作区、启用 `dorisSqlLite.sqlParameters`、本机可用 PowerShell：优先 `pwsh`，Windows 未找到时回退 `powershell.exe`，不绕过本机执行策略。
- 脚本 stdout 只输出非空 UTF-8 JSON 数组，例如 `[{"biz_date":"2026-10-01"},{"biz_date":"2026-10-02"}]`。每项为参数对象；值可为非空字符串、有限数字或布尔值，最终按文本替换。无参数可用 `[{}]`；单批也必须输出数组，PowerShell 可用 `ConvertTo-Json -InputObject $batches -Compress` 保留数组。
- 右键/命令面板 `Doris SQL Lite: 顺序分批执行 SQL` 才运行脚本；普通执行/计划只处理当前语句。脚本生成参数后，扩展检查全部批次并显示数量、首尾参数、初始化、步骤与连接，点击“开始执行”才提交 SQL。`throw`、`Write-Error`、非零退出码、非法参数或脚本取消都会阻止提交；诊断可写 stderr。stdout/stderr 上限分别为 4 MiB/8 KiB，整次任务最多执行 10,000 个步骤，过大时缩小脚本日期范围。
- SQL 和参数在启动时固定，编辑只影响下一次任务。同一文件锁贯穿脚本、确认和执行；批次、步骤依次等待完成，其他文件可独立操作。所选步骤不支持 `@output`；实际返回结果集会停止任务，不提供批量结果预览或多批 TSV 导出。
- 运行通知约每秒显示当前阶段、已完整完成批数、当前批次/步骤、连接、参数摘要以及任务和本步耗时。任务计时从确认启动开始，本步包含准备会话的时间；耗时不能当作完成百分比或预计剩余时间。通知最多展示三个参数，每项至多前 48 个字符，超量/超长/换行会明确省略，完整值读最终报告。取消后等待“取消收尾”完成。
- 失败、取消或连接断开后停止后续步骤，等待当前操作收尾，不自动重连、重试、重放初始化、回滚或补偿。即使清理当天成功、回填失败，该清理也不会自动恢复。核对已完成步骤和不确定写入后再调整脚本起始日期重跑，不直接从首批重复执行。

## 读取执行反馈

普通查询、直接执行并导出、面板导出、计划及分批任务使用同一简短格式，不附带 SQL 正文、结果行或计划全文。结果页、导出通知、无结果集操作及批次结束通知有复制/保存入口；也可用 `Doris SQL Lite: 复制最近一次执行反馈` / `保存最近一次执行反馈` 获取当前窗口最近完成的一次操作。Reload Window 后记录清空，不建立查询历史。

- 先核对 `schemaVersion=1`、`extensionVersion`、`name`、`connectionName`、`databaseType`、`parameters`、`source.path` 及执行时行号，确认属于当前任务。普通操作 `databaseType=null` 表示未确定类型，不自行猜数据源。`action` 区分 `query` / `export` / `explain` / `batch`，`status` 区分 `success` / `failed` / `cancelled`。`hasResultSet` 按驱动实际返回判断，`affectedRows=null` 表示服务端未提供影响行数，不能说成 0 行。
- 分批任务的默认摘要用 `batch.steps` 将名称、连接类型和 SQL 行号各列一次，行号共用根 `source.path`。`firstBatch` / `lastBatch` 是首尾参数和状态样例，不代表中间连续或全部成功；仅一批时不重复末批。`batch.stopped` 标出停止位置、该批参数、`completedSteps` 和 `needsReviewSteps`，先据此定位成功清理和失败回填的边界。
- 通过 `batchReportFile` 读取完整 JSON 报告的 `batch.records`，核对全部步骤和实际参数。`phase=init` 为初始化，`batchIndex` 从 1 开始；`not-run` 未执行，`submitted=false` 未提交该步，`completedBatches` 只计整批全部成功。混合引擎以各步骤类型为准。`needsReview=true` 需核对实际写入，不能按“失败/取消”推断未改数据；已成功但随后会话断开的步骤仍可为 `success`，结合任务错误判断停止原因。
- 已提交 SQL 的任务首次复制先选择本地 `.json` 保存完整报告，默认文件名以 `.batch-report.json` 结尾；保存 `.md` 反馈会自动配套报告，只选一次位置。后续复用路径，报告被删则重新保存。报告和批次 Markdown 不覆盖已有文件；取消或保存失败不复制缺少报告位置的材料。尚未提交任何 SQL 时直接给简短反馈，不要求报告。保存失败只重试保存，不重复执行 SQL；清理失败给出的残留不能当作完整报告。
- `source.savedAtExecution=false` 表示当时有未保存内容，`changedSinceExecution=true` 表示后来编辑过文件，`null` 表示当前状态未核对（如文件已关闭）。这些情况下，当前磁盘文件不能直接当作执行版本；按任务需要核对或让用户提供显式“复制完整材料”的计划快照，不自动强制保存、不生成指纹。
- `submitted=false` 表示本次未再提交 SQL，可能是执行前取消/失败，也可能是把完整内存结果保存成文件；需结合 `action` 和 `status` 判断。`totalRows=null` 表示总行数未知，`rowsRead` 不能代替总数。`previewLimit` 只表示工具自动追加的上限，SQL 自带 LIMIT 仍在来源中。
- `resultFile` 指向完成的结果，`planFile` 指向完整计划，`batchReportFile` 指向完整逐步报告；按需读文件，不要求用户反复粘贴全文。`temporaryFile` 是清理失败时的残留，不是成功产物。`sessionState=lost` 时先按当前任务要求恢复初始化；错误/警告已脱敏并可能明确截断，必要时再查对应信息，不自动重试 SQL。

## 结果导出与会话

- 已知需要完整数据时，优先在查询前写 `-- @output: results/orders_2026-10-27.tsv`，再按 `Ctrl+Enter`；或者使用右键/命令面板的 `Doris SQL Lite: 执行并导出完整 TSV`。查询只执行一次，逐行写 TSV，不注入预览 `LIMIT`、不受预览/读取行数设置限制，SQL 自带 `LIMIT` 保留；成功提示实际行数、路径和耗时，不打开预览。沿用当前文件、连接的会话和参数。
- `@output` 只影响下一条 SQL，不设文件默认输出。路径按原文解释，不加外围引号、不支持 `${...}` 路径替换；相对路径以已保存的本地 SQL 文件目录为准，父目录自动创建。未保存文件应使用绝对路径，或不写 `@output`、通过导出命令选择保存位置。注释路径优先于默认导出目录；无注释时命令使用默认目录和时间戳文件名，未配置则弹保存对话框。
- 此入口用于单条结果查询（`SELECT` / `WITH…SELECT` / `SHOW` / `DESCRIBE` / `EXPLAIN`），拒绝写入、`CALL`、多语句和服务端 `INTO OUTFILE`。输出必须为文件系统上的 `.tsv`，并支持同目录硬链接；不支持虚拟文件提供器。重复列名会拒绝导出，查询应使用唯一 `AS` 别名。零行结果仍有列头。直接导出不额外询问未知行数，不意味着已审核扫描成本。
- 本地 TSV 先写唯一 `.partial`，完成后才生成正式文件；已有目标不覆盖，需换文件名。取消、数据库/磁盘失败时清理临时文件，不自动重跑；清理失败会给残留路径，强制退出可能遗留 `.partial`，不能把它当作成功结果。先确认操作结束再清理。单行和驱动批次仍占内存，缓冲上限不等于结果行大小没有限制。
- 预览默认最多保留 1000 行，并可能追加 `LIMIT` 或提前停止读取；截断或提前停止时不能据显示行数推断总数。计划按原 SQL 完整获取，不追加预览 `LIMIT`。
- 复制 TSV 只取面板保留的行。排序与筛选作用于已加载行，复制与导出保持查询返回顺序。预览后仍可用面板“导出 TSV”取全量；各入口均使用 UTF-8、无 BOM，默认启用表格公式转义，需原值时按下游要求处理该设置。
- 完整保留的结果直接导出。截断结果会在原会话重跑原查询，数据以重跑时为准；同一会话执行过其他语句（包括查看计划和失败的语句）、关闭、断线或重置后，旧结果不能重跑导出，需要重新查询。因此需要全量结果时，在本次查询后及时导出，不在中间插入其他语句。
- 每个文件按连接 ID 保留独立会话，切换数据源再回来保留原 `USE`、`SET` 等状态；不同文件互相隔离。同一文件的查询、计划、参数选择、导出和分批任务互斥，其他文件可独立执行。
- 取消可用进度通知、状态栏或 `Doris SQL Lite: 取消当前查询`。取消后会话仍健康则保留；已断开时重新执行必要初始化，不自动重放或重试失败语句。
- 关闭文件、重置会话、修改连接目标/认证信息等会释放相应会话。`Doris SQL Lite: 重置当前文件的会话` 取消当前操作并重置该文件全部会话；之后重新执行初始化。连接按实际使用懒建立，不自动回收空闲会话，多文件、多数据源会增加保留的连接数。

当前未支持自动执行文件全部语句、独立命令行/服务器调度、并行批次、自动断点续跑、路径参数替换及自动 AI 审核；交付时不要发明其他指令。已生成 SQL、通过审核、开始导出与文件完整生成是不同状态，按实际结果说明。
