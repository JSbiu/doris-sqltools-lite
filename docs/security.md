# 安全模型

## 本地边界

Doris SQLTools Lite 在当前 VS Code 扩展进程中运行。SQL、参数、结果、计划和错误诊断默认留在本机，扩展不包含遥测、自动上传或自动调用 AI 服务的路径。

用户主动执行“复制”“导出”或把资料交给其他工具时，材料进入系统剪贴板或本地文件。

## 连接元数据

`dorisSqlLite.connections` 保存：

- 连接 ID 与显示名称。
- 类型、主机、端口和默认数据库。
- 用户名。
- TLS 与 Spark 认证方式。

该设置使用 `scope: machine`，保存在 VS Code 用户设置，不写入项目 `.vscode/settings.json`。

## 密码

- 密码只写入 VS Code SecretStorage。
- 连接清单、日志、复制包和测试夹具不包含密码。
- 新增连接时留空表示暂不保存；编辑时留空表示保持原密码。
- 已保存密码认证失败时，扩展清除该密码并重新询问一次。

SecretStorage 保护静态存储。扩展进程打开连接时仍需要在内存中取得密码，因此同一 Windows 用户下的恶意进程或恶意扩展仍可能读取运行中的凭据。

## 查询参数

SQL 参数值是业务数据，保存在 VS Code 扩展状态：

- 有工作区时使用工作区状态。
- 没有工作区时使用本机全局状态。
- 参数不写入 `settings.json`，不参与 Settings Sync。
- 普通参数保持原值；已声明字段保护的参数按当前字段规则保存。

参数值按“文件 + 参数名 + 声明”关联。修改 SQL 中的默认值会使相应历史值失效。

## 字段保护

### 声明

字段规则来自 SQL 注释：

```sql
-- @default-encrypt: {"user_id":"user","phone":"phone"}
-- @encrypt: {"order_id":"order"}
```

- 键精确匹配结果列名、唯一 `AS` 别名或 SQL 参数名。
- 值是逻辑域。
- 当前语句规则覆盖文件默认规则中的同名字段。
- 未声明字段使用普通输出。

### 算法

字段转换使用 RFC 5297 AES-256-SIV：

- 每个扩展安装生成独立 64 字节数据密钥。
- 密文格式为 `enc:v1:<keyId>:<base64url-domain>:<base64url-payload>`。
- 认证覆盖版本、密钥 ID、逻辑域和值。
- 同密钥、同域、同类型的相同值得到相同密文，支持跨查询对照。
- 不同值、不同类型和不同域得到不同密文。
- 密文比原值长，可能暴露相等关系和字段长度变化。

### 类型

字段保护保留：

- 字符串与 UTF-8 文本。
- 有限数字、`-0`、大整数。
- 布尔值。
- 日期。
- 二进制值。
- `null` 与 `undefined`。

驱动在读取阶段已经丢失的精度无法恢复。跨数据源对照 ID 时，需要让 SQL 返回相同类型。

### 密钥

- 数据密钥保存在 SecretStorage。
- 密钥在首次需要字段保护时按需生成。
- “导出字段加密密钥”写出包含敏感密钥的 JSON 文件。
- “导入字段加密密钥”保留现有密钥并切换活动密钥。
- 已有结果继续使用执行时的密钥快照。

导出的密钥文件应按高敏感凭据管理。丢失密钥后，单独持有密文无法恢复原值。

### 输出边界

字段保护只作用于结果数据、复制和导出中的已声明字段：

- 结果 Tab 显示“N 字段已保护”只读徽章。
- 计划正文和 SQL 引用始终可见，便于 AI 审核；字段保护不遮挡计划。
- 复制和导出在操作开始时固定规则与密钥。
- 没有声明的语句不显示保护徽章，也没有全局状态栏提示。
- 字段原文切换、密钥导入导出和单值解密保留在命令面板，不进入日常右键菜单。

字段保护处理的是 SQL 注释声明的结果字段。连接密码继续由 SecretStorage 管理。

## TLS

MySQL / Doris TLS 默认：

- 校验证书链。
- DNS 主机同时校验证书主机名。
- 系统信任库作为默认 CA。
- `sslCaFile` 可指定私有 PEM CA。

`sslVerify=false` 接受服务器提供的证书，用于已确认可信的私有或临时证书目标。

Spark Thrift 使用 SASL/PLAIN 或 NOSASL。生产环境可以在网络层提供加密和访问控制；连接表单当前管理 HiveServer2 的认证方式。

## 工作区信任

普通查询、结果查看和连接管理可以在受限工作区使用。

分批执行会运行工作区中的 PowerShell 参数脚本，因此要求：

- 工作区已受信任。
- 用户显式执行分批命令。
- 参数脚本路径和内容属于当前受信任项目。

参数脚本不接收密码。脚本的 stdout 只用于 JSON 参数；stderr 用于诊断。

## 文件写入

TSV、计划、复制包和批次报告遵循以下边界：

- 不覆盖已有目标。
- 不覆盖源 SQL、参数脚本或已有结果文件。
- 使用同目录临时文件和排他发布完成写入。
- 失败时删除本次创建的未完成文件。
- 无法清理时明确给出残留路径。

## 错误与日志

- 密码和凭据形状文本在错误信息中脱敏。
- 反馈 JSON 中的错误与警告最多 2000 字符；输出面板保留本次完整错误，复制和导出也使用完整文本。
- 本地 JavaScript stack frame 不进入错误引用；服务端返回的诊断原文按安全边界显示。
- 字段保护不改变错误消息中的密码脱敏。

## 复制与导出

复制分两种：

- `@copy: extra`：引用链接、引擎/连接、参数、耗时、计划正文或结果摘要与 TSV。
- `@copy: origin`：只复制当前 Tab 的原始内容。

SQL 正文不进入默认复制包，只给 Codex 可点击的本地文件引用。结果、计划和错误 `extra` 对未保存 SQL 不复制正文；显式“复制 SQL 引用”或错误引用才回退为带语言标记的原始 SQL 模板。受保护参数按当前字段模式输出，字段密文模式下复制包只带密文。复制包和导出文件由用户明确触发；扩展不自动发送到远端服务。

字段保护下的复制和导出使用操作开始时的规则与密钥快照。把材料交给外部服务前，处理范围和数据分类由用户与当前任务决定。

## 安全报告

安全问题通过仓库的 GitHub Security Advisory 入口私下报告：

<https://github.com/JSbiu/doris-sqltools-lite/security/advisories/new>

报告中请提供受影响版本、复现条件、实际影响和最小验证材料。不要在公开 issue 中附真实密码、连接串或业务数据。
